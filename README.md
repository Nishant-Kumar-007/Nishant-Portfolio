## 🏎️ Overview

An interactive, responsive portfolio built with pure modern web technologies (HTML5, Vanilla CSS3, JavaScript, and WebGL Canvas). Designed around high-velocity motorsport precision and software craftsmanship.

### ✨ Key Features

- **Dynamic Hero 3D Card Rig**: Perspective-driven interactive card with pop-out motion graphics overlay.
- **Multi-Skin Theme Engine**: Switch effortlessly between:
  - 🏁 **Dark F1**: Pitch black, high contrast racing livery with signature red and gold accents.
  - ⚡ **Cyber Neon**: Synthwave neon cyan and magenta palette.
  - 🎨 **Pastel Studio**: Clean, minimalist editorial light theme.
  - 👾 **Retro Arcade**: Scanlines and 8-bit fluorescent green terminal vibe.
- **Interactive SWE Pillars Flip Cards**: Explore Software Engineering focus areas (Full Stack, Agentic AI, Cloud & DevOps, System Architecture, Competitive Coding).
- **Hackathon & Project Showcase**: Detailed breakdowns of 25+ hackathons, awards, tech stacks, and live demos.
- **Driver Card Generator**: Interactive badge generator with real-time customization.

---

## 🛠️ Tech Stack

- **Markup & Styling**: Semantic HTML5, Modern CSS Grid & Flexbox, CSS Custom Properties (`var(--...)`), CSS 3D Transforms
- **Animation & Graphics**: Vanilla JavaScript, RequestAnimationFrame render loop, WebGL / Canvas effects
- **Zero Heavy Dependencies**: 100% lightning-fast loading with zero runtime bloat.

## 💻 Local Development

To run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/Nishant-Kumar-007/Nishant-Portfolio.git

# Navigate into the project directory
cd Nishant-Portfolio

# Open index.html directly or serve using any static server:
npx serve .
# or
python -m http.server 3000
```
